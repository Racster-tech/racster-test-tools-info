Privacy information — Racster TEST mail reader

This notice describes this specific internal test-email tool, not the customer-facing Racster service.

Data accessed and purpose

The tool reads the connected account identifier and searches for an exact test email. For a matching test message it reads the email, headers and attachments to verify delivery, approved wording and the expected test PDF. It requests only the Gmail read-only permission. It does not send, edit or delete Gmail messages.

Storage and processing

OAuth credentials are stored in access-restricted local files, separately from source control and public reports. Test evidence is retained in the private Racster development workspace and any configured private backups. Authorised maintainers and configured development automation may process test evidence to diagnose failures and verify outcomes. These public information pages contain no mailbox data or credentials.

The tool does not sell mailbox data, use it for advertising, or use it to train general-purpose AI models. Access, use and transfer of Google API data are limited to the stated test-verification purpose and must comply with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Test-operation evidence is retained for traceability and recovery until an authorised maintainer removes it under the project’s retention rules. There is no automatic deletion period currently configured for this tool. The owner can revoke the connection at Google Account connections. Revocation stops future access; it does not automatically delete previously retained local evidence or backups. Contact support@racster.com to request removal of retained test data.
