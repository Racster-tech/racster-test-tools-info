Racster TEST mail reader

A private development tool for Racster’s authorised maintainers. It checks whether a specific synthetic test email and its expected attachments arrived in the designated test mailbox.

This is not the Racster customer application. It does not provide public mailbox access, send email, change messages or manage bookings.

Access and operation

The mailbox owner grants read-only Gmail access once. A local reader can then renew access in the background. Each read is restricted by the tool to an existing test-operation record, the designated test mailbox, sender and exact message identifier or narrow time window. The matching test-run marker is checked before evidence is accepted.

Google’s Gmail read-only permission technically covers the mailbox; the additional test-only restrictions are enforced by this tool. Do not connect a production or customer mailbox.
